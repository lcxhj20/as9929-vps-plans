## 常见问题

**9929 的延迟一般是多少？**

分口径。机房到国内的链路延迟，美西 9929 一般 150–190ms；第三方测的全国三网平均多在 163–176ms；本地宽带直接 ping 会到 180–196ms。三个区间都对，测的位置不同。

**电信用户该不该选 9929？**

电信有 CN2 GIA 这条更对口的线，纯 9929 产品对电信用户是“能用但不是最优”。像 Akile 洛杉矶这种电信回程走 CN2 GIA、联通走 9929 的组合，反而三家都不吃亏。你要是纯电信宽带又只追一条线，优先看 CN2 GIA 产品。

**原生 IP 和住宅双 ISP 怎么选？**

做跨境账号、流媒体解锁，住宅双 ISP 的判定通过率更高，代价是同配置贵 35%–40%。建站、跑 API、挂长连接，原生 IP 完全够用，便宜的那部分钱花在带宽上更值。

**年付值不值？**

折扣幅度通常在 15%–25%，换来的是一年锁定期。第一次用某家、或者还没测过线路的，先月付跑一个晚高峰再决定。

**买了不满意能退吗？**

看商家。CstoneCloud 云服务器 24 小时无理由退款（IP 未被封），DigitalVirt 正价商品流量不超 10G 可全额退但用码商品除外，Akile 的公开资料里没有明确条款，下单前直接问客服最快。
